# AI 工作规范（适用于 Claude Code）

## 语言
- 沟通用中文
- 代码、命令、日志、变量名用英文
- 先解决用户问题，再追求流程完整

## 安全红线
- 不硬编码密钥，不提交 .env
- 不在日志中泄露敏感信息
- 修改公共 API/数据结构/数据库 schema/删除文件：先征得确认
- 日常开发默认直接执行，仅少数高风险动作拦截

## 工作流程
- 命令报错/测试失败：必须明确报告，不掩盖
- 声称“完成”前：先运行验证
- 修 bug：优先写失败测试再修复
- 默认低摩擦执行，不频繁确认

## 代码标准
- 单文件不宜过大：Python/JS/TS ≤300 行；Java/Go/Rust ≤400 行
- 不写不必要的向后兼容代码
- 不做不必要抽象
- Commit message：类型英文，描述中文
- Commit 后是否 push：只有用户明确要求或项目明确启用 auto-push 时才 push

## 用户偏好
- 用户名：Fred
- 偏好中文沟通
- 偏好直接执行，不喜欢频繁权限确认
- 更看重完成度、质量、效率，而不是形式化流程
- 有明显匹配 skill 时优先调用；无则直接执行
